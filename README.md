# Tic Tac Toe

# Description 
This is a web-based Tic Tac Toe game. 
Where players take turns placing X (cross) and O (circle).

# Features
- Circle is always first
- Draw
- Highlights the winner
- Restart button to keep on playing
- Scoreboard to keep track of whose winning/losing

# How I made This
- HTML 
- CSS 
- JavaScript

# Motivation
I wnated to make interactive web game to practice mt HTML, CSS and JavaScript skills

# Challenges/Learning
I learned how to highlight the winner, detect draw, create a restart button, and create a the game.
A challenging part was fixing the bugs and using arrays.
